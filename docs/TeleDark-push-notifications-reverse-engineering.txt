8. ЧТО НУЖНО СДЕЛАТЬ В СВОЁМ КЛИЕНТЕ (ПОШАГОВЫЙ ПЛАН)
================================================================================

Ниже — практический план воспроизведения схемы TeleDark для своего клиента.
Каждый пункт привязан к тому, что найдено в IPA.


ШАГ 1. Bundle ID
----------------
  - Выбери постоянный explicit Bundle ID (у TeleDark: app.teledark)
  - НЕ меняй его при переподписи
  - Все extensions: <твой.bundle.id>.NotificationService и т.д.
  - Зарегистрируй App ID в Apple Developer Portal


ШАГ 2. Apple Developer сертификат
----------------------------------
  - Платный Apple Developer Program ($99/год)
  - Создай App ID с capabilities:
      [x] Push Notifications
      [x] App Groups
      [x] Time Sensitive Notifications (если нужны)
      [x] Communication Notifications (если нужны)
  - Создай provisioning profile (Development или Distribution/Ad-Hoc)
  - Убедись что в профиле есть:
      aps-environment = production (или development для теста)
      com.apple.security.application-groups = твои группы


ШАГ 3. Entitlements в Xcode/Bazel
---------------------------------
  В .entitlements главного приложения:
    <key>aps-environment</key>
    <string>production</string>

    <key>com.apple.security.application-groups</key>
    <array>
      <string>group.ТВОЙ_ID.1</string>
      ...
    </array>

  То же для КАЖДОГО extension (NotificationService, NotificationContent, Widget...)


ШАГ 4. UIBackgroundModes
------------------------
  В Info.plist:
    <key>UIBackgroundModes</key>
    <array>
      <string>remote-notification</string>
      <string>voip</string>
      <string>fetch</string>
      <string>audio</string>
      <string>location</string>
      <string>processing</string>
    </array>

  (минимум для push: remote-notification; остальное — как в Telegram)


ШАГ 5. Notification Extensions
-------------------------------
  Обязательно включи и подпиши:
    - NotificationService extension (com.apple.usernotifications.service)
    - NotificationContent extension (опционально, для кастом UI)

  Bundle ID extensions должен быть под тем же Team ID.
  Все extensions подписываются ОДНИМ профилем/сертификатом с app.


ШАГ 6. App Groups
-----------------
  - Создай App Group в Developer Portal
  - Пропиши одинаковые group.* во всех таргетах (app + все extensions)
  - Telegram использует 5 групп: group.1f56048729375e2d.{1,2,3,4,5}
  - У тебя будут свои group.ТВОЙ_TEAM_ID.* — это нормально


ШАГ 7. Фикс для сайдлоада (аналог TeleDark dylib)
--------------------------------------------------
  TeleDark решает проблему переподписи через runtime hook:

    NSFileManager
      - containerURLForSecurityApplicationGroupIdentifier:

  Тебе нужен аналог если распространяешь IPA для переподписи чужими
  сертификатами. Варианты:

  A) Написать dylib на Theos/Logos:
     %hook NSFileManager
     - (NSURL *)containerURLForSecurityApplicationGroupIdentifier:(NSString *)id {
       // подставить корректный путь для текущего сертификата
       return %orig или кастомный URL;
     }
     %end

  B) Использовать готовые: sideloadFixerLol.dylib / TelegramNotificationFix.dylib
     (но они заточены под Team LKRRVC93D7 и polarbear App ID — нужна адаптация)

  C) Если пользователь подписывает СВОИМ сертификатом с правильными
     App Groups в профиле — хуки могут быть не нужны, всё заработает
     нативно при корректной подписи всех таргетов.


ШАГ 8. Подпись IPA
------------------
  Инструменты (поддерживаются каналом): ESign, Scarlet, GBox, Feather, KSign

  При подписи:
    1. Импорт .p12 + .mobileprovision
    2. Выбрать IPA
    3. НЕ менять Bundle ID
    4. Подписать app + ВСЕ extensions + frameworks
    5. Установить на устройство (UDID должен быть в профиле для Ad-Hoc)

  Файл SignedByEsign в TeleDark подтверждает что использовался ESign.


ШАГ 9. Проверка на устройстве
-----------------------------
  1. Настройки iOS → Teledark/твой клиент → Уведомления → Разрешить
  2. Внутри приложения: Настройки → Уведомления (Telegram settings)
  3. Убедиться что app не в Focus/Не беспокоить
  4. Background App Refresh включён
  5. При проблемах в РФ: MTProto proxy или стабильный VPN (вне scope реверса,
     но канал ZiSipa упоминает работу без VPN для мода)
