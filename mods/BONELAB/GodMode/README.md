# God Mode (BONELAB MelonLoader mod)

Добавляет в **BoneMenu** страницу «God Mode» с переключателем **«Бессмертие»**.
Когда включён — игрок не получает урон и не умирает.

## Как работает

Harmony-префиксы на методах `Il2CppSLZ.Marrow.Player_Health`:
- `TAKEDAMAGE` — обычный урон
- `ApplyKillDamage` — мгновенное убийство
- `Death` — прямой вызов смерти

Когда «Бессмертие» включено, префикс возвращает `false` → оригинальный метод
не выполняется → урон/смерть отменяются. Выключаешь — всё работает как обычно.

Имена методов взяты не по памяти, а вытащены из метаданных твоего
`Il2CppSLZ.Marrow.dll` (с очков), API BoneMenu — из исходников BoneLib в репо
(`Page.CreatePage` / `Page.CreateBool`). Мод скомпилирован (0 ошибок) против
настоящих `BoneLib.dll` и `MelonLoader.dll` v0.6.5.

## Установка (через VR CONTROLER, без ADB — папка вне Android/data)

1. Убедись, что стоит **BoneLib** (он и так нужен для Fusion — уже есть).
2. Положи `GodMode.dll` → `MelonLoader/Mods/`
3. Запусти BONELAB → открой BoneMenu → страница **God Mode** → тумблер **Бессмертие**.

Лог применения патчей — в `MelonLoader/Latest.log` (строки «God Mode: пропатчен …»).

## Проверено / не проверено

- **Компиляция**: да, против реальных сборок, 0 ошибок; имена методов сверены с
  метаданными игровой сборки.
- **Рантайм на устройстве**: нет — нет ни очков, ни игры в этом окружении.
  Если какой-то путь урона не покрыт (например, падение в бездну/раздавливание
  идёт мимо этих трёх методов) — скинь `Latest.log`, добавлю нужный метод.

```bash
cd mods/BONELAB/GodMode
dotnet build -c Release GodMode.csproj   # net8, референсы см. в .csproj
```
