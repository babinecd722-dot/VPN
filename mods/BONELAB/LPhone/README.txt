--------------------------------------------------------------------------------
КАК ЭТО УСТРОЕНО (важно для дальнейшей работы)
--------------------------------------------------------------------------------
UI рисуется СОФТВЕРНО в Texture2D, а не через Unity Canvas.

Почему так:
  - в Il2Cpp рантайм-Canvas капризен (шрифты, ивент-система, лейаут);
  - на Quest перестройка Canvas дороже, чем залив готовой текстуры;
  - у нас перерисовка только при изменении (Gfx.MarkDirty + Present),
    часы дёргают её раз в минуту -> почти нулевая нагрузка;
  - весь экран = 1 материал = 1 draw call.

Классы:
  Gfx.cs          софтверный рендерер: Rect, RoundRect (со сглаживанием),
                  Circle, VGradient, Blit, BlitRounded, Text + растровый шрифт
  Font            атлас 174 глифа (латиница + кириллица), запечён в font.png/bin
  Assets.cs       загрузка встроенных ресурсов (меш, обои, иконки, шрифт)
  PhoneBuilder.cs сборка GameObject: меши, материалы, физика, хват
  PhoneOS.cs      состояние, экраны, жесты, отрисовка
  TouchInput.cs   палец -> UV -> пиксели
  LPhoneMod.cs    точка входа, BoneMenu

Экран: 742 x 1600 пикселей = 74.2 x 160.0 мм, то есть 1 px = 0.1 мм.
Верхние 150 px зарезервированы под Dynamic Island (Phone.SafeTop).

--------------------------------------------------------------------------------
ДОРОЖНАЯ КАРТА (следующие этапы)
--------------------------------------------------------------------------------
Этап 2 — Камера и Галерея (локально, без сети):
   - Camera: Unity Camera + RenderTexture на позиции задней/фронтальной камеры,
     переключение объектива, кнопка спуска, вспышка-затвор
   - снимок -> Texture2D -> Галерея (сетка превью, просмотр, удаление)
   - экспорт снимка на Quest: /sdcard/Download/LPhone/  (кнопка "Сохранить")
   ВАЖНО по производительности: превью камеры рендерим 15 fps в 512x512,
   и только пока приложение открыто, иначе на Quest просядет FPS.

Этап 3 — L Store:
   - карточка Messenger в стиле стора, кнопка GET, прогресс 5 сек, установка
   - иконка появляется в доке (PhoneOS.InstallMessenger уже готов)
   - перетаскивание и удаление иконок долгим нажатием

Этап 4 — Messenger (сеть, LabFusion):
   - контакты = игроки лобби, круглые аватарки как в Fusion, ники
   - переписка, отправка фото из галереи
   - контакт BE PRIME с бейджем AUTHOR, открывает ленту @be_primex
   - голосовой звонок: свой канал поверх Fusion-войса без затухания по дистанции
   - видеозвонок: JPEG-кадры низкого разрешения (реалистично ~128x128 @ 5 fps —
     это предел того, что тянет сеть Fusion без лагов)
   - входящий звонок: рингтон + карточка звонящего + приём свайпом
   - в звонке: динамик / микрофон / переключение на видео

Честно про технические границы, чтобы не было сюрпризов:
  - Камера в игре = виртуальная камера сцены. Доступа к настоящим камерам
    Quest у мода нет (Meta их не отдаёт обычным приложениям).
  - "Веб-версия" Telegram внутри телефона невозможна как настоящий браузер —
    в игре нет движка рендеринга веба. Реалистичный вариант: тянуть t.me/s/
    по HTTP и рисовать ленту своими средствами (текст + картинки).
  - Переписка и галерея живут в памяти на время лобби, как ты и просил;
    на диск уходит только то, что сам сохранишь кнопкой.

  "модель загружена: 21 частей"      — меш ок
  "шрифт: 174 глифов"                — шрифт ок
  "шейдер: ..."                      — какой шейдер подхватился
  "хват установлен"                  — грип встал
  "хват не установлен: ..."          — телефон будет просто физическим предметом,
                                       скинь эту строку, поправлю под твой билд

Пересборка:  dotnet build -c Release

  make_font.py    запекание растрового шрифта -> res/font.png + font.bin
  mock_ui.py      мокап экранов теми же координатами, что в PhoneOS.cs
  preview.py      софтверный рендер модели без Blender
