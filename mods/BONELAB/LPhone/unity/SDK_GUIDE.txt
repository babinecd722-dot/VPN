================================================================================
LPhone — сборка паллета в Marrow SDK (Unity)
================================================================================
Зачем это нужно, а не рантайм-сборка модом:

  1. MarrowEntity -> LabFusion СИНХРОНИЗИРУЕТ телефон автоматически.
     Без этого другие игроки его вообще не видят, и мессенджер/звонки
     сделать физически невозможно.
  2. Настоящий Grip -> правильный хват, поза пальцев, притягивание
     утилити-ганом. Добавить эти компоненты в рантайме нельзя: проверено
     на устройстве, AddComponent<BoxGrip> роняет игру нативно.
  3. Телефон появляется в СПАВН-ГАНЕ в своей папке.
  4. Корректные слои физики, масса, коллизии, пулинг и деспавн.

Делишь так: ПАЛЛЕТ несёт модель + физику + грип, КОД-МОД несёт экран,
интерфейс и сеть.

--------------------------------------------------------------------------------
ДОГОВОР С КОД-МОДОМ (единственное жёсткое требование)
--------------------------------------------------------------------------------
Внутри префаба должен быть меш-объект с именем РОВНО:

        Screen_UI_Anchor

Это плоская панель экрана с UV 0..1. Мод сам её найдёт, создаст текстуру
интерфейса и будет в неё рисовать. Больше мод от паллета ничего не требует.

Если имя не совпадёт — телефон будет обычным пропом без экрана.

--------------------------------------------------------------------------------
ИСХОДНАЯ МОДЕЛЬ
--------------------------------------------------------------------------------
  unity/LPhone17ProMax.obj  (+ .mtl)   — 21 объект, 2408 треугольников
  unity/LPhone17ProMax.glb             — то же с PBR-материалами

  Масштаб: МЕТРЫ 1:1. При импорте в Unity ставь Scale Factor = 1.
  Ориентация: +Z = лицевая сторона (экран), +Y = верх телефона.
  Габариты корпуса: 77.6 x 163.4 x 8.75 мм.

  Импорт: Model -> Scale Factor 1, Read/Write НЕ нужен, Generate Colliders НЕТ.

ШАГ 1. Пустой паллет
--------------------------------------------------------------------------------
  Marrow SDK -> Create Pallet
     Title:  LPhone
     Author: BE PRIME
  (появится ассет паллета в проекте)

--------------------------------------------------------------------------------
ШАГ 2. Префаб телефона
--------------------------------------------------------------------------------
  1. Перетащи модель в сцену. Переименуй корень в  LPhone_17_Pro_Max
  2. Проверь, что среди детей есть объект  Screen_UI_Anchor
  3. На КОРЕНЬ добавь:

     Rigidbody
        Mass                  0.22
        Drag                  0.05
        Angular Drag          0.35
        Collision Detection   Continuous Dynamic
        Interpolate           Interpolate

     Box Collider
        Center  (0, 0, 0)
        Size    (0.0776, 0.1634, 0.00875)

     InteractableHost          (компонент SLZ)
     BoxGrip                   (компонент SLZ)
        Is Throwable          ON
        Grip Colliders        -> перетащи сюда Box Collider с корня

     MarrowEntity              (компонент SLZ — ОБЯЗАТЕЛЕН для Fusion)

  4. Сохрани как префаб.

  Примечание: у SLZ обычно есть валидатор/кнопка авто-настройки в инспекторе
  крейта — если он предложит доставить недостающие компоненты, соглашайся,
  он знает про свои зависимости лучше нас.

--------------------------------------------------------------------------------
ШАГ 3. Материалы
--------------------------------------------------------------------------------
Шейдер: URP/Lit (или SLZ/LitMAS Standard — им игра рисует свои пропы).
Цвета в sRGB:

  M_Alu_CosmicOrange   #E8763A   Metallic 0.85   Smoothness 0.60   корпус
  M_Alu_Dark           #D2551F   Metallic 0.85   Smoothness 0.66   плато, кнопки
  M_BackPanel_Glass    #EE7B33   Metallic 0.30   Smoothness 0.72   задняя панель
  M_LensRing           #C7C7CC   Metallic 1.00   Smoothness 0.78   оправы линз
  M_LensGlass          #04070E   Metallic 0.35   Smoothness 0.95   стёкла линз
  M_DynamicIsland      #191919   Metallic 0.00   Smoothness 0.90   островок
  M_Black              #080808   Metallic 0.00   Smoothness 0.65   порт, мелочь

  M_Screen  — ОСОБЫЙ. Материал экрана:
     шейдер URP/Unlit (чтобы экран светился сам, а не зависел от света сцены)
     Base Map оставь пустым — текстуру подставит мод в рантайме
     Base Color белый

--------------------------------------------------------------------------------
ШАГ 4. Крейт и папка в спавн-гане
--------------------------------------------------------------------------------
  Marrow SDK -> Create Crate -> Spawnable
     Title:     LPhone 17 PRO MAX
     Pallet:    LPhone
     Prefab:    LPhone_17_Pro_Max
     Tags/категория: Phone      <- по этому полю спавн-ган раскладывает по папкам

--------------------------------------------------------------------------------
ШАГ 5. Экспорт и установка
--------------------------------------------------------------------------------
  Marrow SDK -> Build Pallet (платформа Android для Quest!)
  Готовую папку паллета положить на очки в:

     /storage/emulated/0/Android/data/com.StressLevelZero.BONELAB/files/Mods/

  Код-мод LPhone.dll остаётся там же, где и был:

     /storage/emulated/0/MelonLoader/com.StressLevelZero.BONELAB/Mods/

--------------------------------------------------------------------------------
ПРОВЕРКА
--------------------------------------------------------------------------------
Спавнишь телефон из спавн-гана. В Latest.log должно появиться:

     [LPhone] подхвачен телефон из паллета: LPhone_17_Pro_Max

Это значит мод нашёл Screen_UI_Anchor и включил экран. Дальше телефон
берётся штатным хватом SLZ, притягивается утилити-ганом и виден другим
игрокам в Fusion.

Если строки нет — проверь имя Screen_UI_Anchor (регистр важен).
