# SaveInstaller (BONELAB MelonLoader mod)

Скачивает файл сохранения (ссылка вшита в код), ставит его как `slot_0.save.json`,
удалив остальные `slot_*.save.json`. Работает один раз при старте игры
(`OnInitializeMelon`, в фоновом потоке, чтобы не подвешивать загрузку), пока не
сотрёшь `installed.marker` или не поменяешь ссылку в коде и не пересоберёшь.

Показывает on-screen сообщение об успехе/ошибке (зелёным/красным) поверх экрана
на ~15 секунд после установки — через `OnGUI()`/`GUI.Label`.

Собрано и проверено компиляцией против настоящей `MelonLoader.dll` (net8, v0.6.5)
из `third_party/MelonLoader-bin/net8/` в этом репозитории. Не тестировалось на
реальном устройстве/игре — только компиляция подтверждена. BONELAB работает на
Il2Cpp, а Unity-референс здесь — обобщённая (Mono) заглушка, поэтому именно
часть с on-screen надписью несёт больше риска не отрендериться так же на
реальном устройстве, чем файловая логика (скачивание/установка сейва) — это
проверено более надёжно через рефлексию по реальному MelonLoader.dll.

## Установка (через VR CONTROLER, без ADB — папка вне Android/data)

1. Положи `SaveInstaller.dll` → `MelonLoader/Mods/`
2. Запусти BONELAB — при первом старте мод скачает и установит сохранение
3. На экране должна появиться надпись «УСПЕШНО...» (зелёная) или «ОШИБКА...» (красная)
4. Подробный лог — в консоли MelonLoader (`MelonLoader/Latest.log`)

## Пересборка

```bash
cd mods/BONELAB/SaveInstaller
dotnet build -c Release SaveInstaller.csproj
```

Нужны референсы `MelonLoader.dll` и `0Harmony.dll` рядом (см. `SaveInstaller.csproj`).
