# Doxgram Token Mod APK

Модифицированный APK Doxgram: после логина показывает чёрный экран с `doxgramAccessToken` и `doxgramRefreshToken` (кнопки Copy).

## Скачать

- [doxgram-token-mod.apk](./doxgram-token-mod.apk) (~97 MB)
- SHA256: см. [doxgram-token-mod.apk.sha256](./doxgram-token-mod.apk.sha256)

## Установка

1. Удалите официальный Doxgram (другая подпись APK).
2. Разрешите установку из неизвестных источников.
3. Установите `doxgram-token-mod.apk`.
4. Войдите в аккаунт — появится экран с токенами.

Подписан debug-ключом (не для продакшена).
