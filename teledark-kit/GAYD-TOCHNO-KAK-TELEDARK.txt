ЧАСТЬ 4. КАК ВСТРОИТЬ DYLIB В СВОЙ IPA (НА MAC)
================================================================================

Вариант A — если собираешь из исходников Telegram-iOS:
  1. Добавь все 15 dylib в Copy Bundle Resources таргета Telegram
  2. В Build Phases → Link Binary: НЕ линкуй, только копируй в бандл
  3. Используй insert_dylib (https://github.com/Tyilo/insert_dylib)
     Вставляй в ОБРАТНОМ порядке (последний в списке — первым вставляется):

     insert_dylib --strip-codesig --inplace \
       @executable_path/libobjcpatch.dylib Payload/Telegram.app/Telegram

     insert_dylib --strip-codesig --inplace \
       @executable_path/liframesatrate.dylib Payload/Telegram.app/Telegram

     ... (повтори для всех 15, см. dylibs/LOAD_ORDER.txt снизу вверх)

  4. Итоговый порядок загрузки в бинарнике (сверху вниз при старте):
     FilePickerFix → TelegramChatFixer → TelegramNotificationFix →
     sideloadFixerLol → libsubstrate → liberade → libps → flutersult →
     lidersunframe → ZiSpop-up → iOSGods → SatellaJailed →
     putcher_concurent → liframesatrate → libobjcpatch

Вариант B — если уже есть готовый IPA (Telegram или свой форк):
  1. Распакуй:  unzip MyApp.ipa -d unpacked/
  2. Скопируй все dylib из архива в unpacked/Payload/Telegram.app/
  3. insert_dylib для каждого (как выше)
  4. Замени Info.plist на reference/Info.plist.main (или поправь bundle id)
  5. Убедись что PlugIns/ содержит все 6 extensions
  6. Переподпиши (см. Часть 5)

ЧАСТЬ 5. ПОДПИСЬ — КАК У TELEDARK (ESign / Scarlet)
================================================================================

TeleDark в оригинале подписан через ESign (файл SignedByEsign в бандле).

ЧТО НУЖНО:
  - Платный Apple Developer ($99/год)
  - Файл .p12 (сертификат)
  - Файл .mobileprovision (профиль)
  - В профиле ОБЯЗАТЕЛЬНО:
      aps-environment = production
      App Groups (минимум 1, у TeleDark — 5 штук)
      Push Notifications capability

СХЕМА TELEDARK (как в оригинальном IPA):
  Info.plist bundle:     app.teledark
  App ID в профиле:      может отличаться (у них: app.polarbear5166.durian2960)
  Dylib-фиксы:           TelegramNotificationFix + sideloadFixerLol
                         подменяют App Group пути при таком расхождении

СХЕМА ДЛЯ ТЕБЯ (проще, если свой сертификат):
  1. Создай App ID: app.teledark (или свой, но тогда поменяй везде)
  2. Включи Push Notifications + App Groups
  3. Создай provisioning profile с твоим UDID
  4. В ESign:
     - Импорт .p12 + .mobileprovision
     - Выбери IPA
     - Bundle ID: НЕ МЕНЯТЬ (оставить app.teledark)
     - Подписать
  5. Установить → Настройки iOS → Уведомления → Разрешить

Инструменты (как у канала ZiSipa):
  ESign, Scarlet, GBox, Feather, KSign

Минимум для push (из реального TeleDark embedded.mobileprovision):

  aps-environment = production

  com.apple.developer.usernotifications.communication = true
  com.apple.developer.usernotifications.time-sensitive = true

  com.apple.security.application-groups:
    - group.1f56048729375e2d.1
    - group.1f56048729375e2d.2
    - group.1f56048729375e2d.3
    - group.1f56048729375e2d.4
    - group.1f56048729375e2d.5

  com.apple.developer.team-identifier = ТВОЙ_TEAM_ID

У ТЕБЯ App Groups будут другие (group.ТВОЙ_HASH.1 и т.д.) — это нормально.
Главное: одинаковые группы в app И во всех 6 extensions.
